# Harness Engineering

This skill provides specialized procedures and calculations for electrical harness engineering.

## Core Capabilities

- **Wire Sizing**: Calculate required wire gauge based on ampacity, voltage drop, and temperature ratings.
- **Circuit Protection**: Determine fuse/breaker ratings based on continuous and surge loads.
- **Pinout Management**: Maintain mappings for complex connector systems.

## Workflow

1. Define system requirements: voltage, current, load type, ambient temperature, wire routing constraints.
2. Select wire gauge (AWG) based on current/length constraints.
3. Determine protection devices.
4. Document the final harness design in a standardized schema.
