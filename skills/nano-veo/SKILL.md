# 视频生成 (Veo 3.1)

视频生成技能，可以通过自然语言或参考图帮助用户生成高质量视频，支持音频同步（对话、音效、环境音）。

## 使用指引

### 第1步：分析需求与参数提取
1. **明确意图**：
   - **文生视频**：根据文字描述生成新视频。
   - **图生视频**：使用图片作为首帧生成视频。
   - **视频扩展**：延长已有视频的长度。
2. **提示词 (Prompt) 编写要点**：
   - **主体 (Subject)**：视频中的核心对象。
   - **动作 (Action)**：主体在做什么（如：行走、旋转、说话）。
   - **风格 (Style)**：艺术风格（如：科幻、恐怖、电影感、卡通）。
   - **镜头与构图**：镜头位置和移动（如：特写、航拍、平视）。
   - **音频线索 (Audio)**：使用引号描述对话（如：他说 "这太神奇了"），显式描述音效（如：轮胎摩擦声）。
3. **关键参数整理**：
   - **Prompt (必需)**：详尽的描述文本。
   - **Input Image (可选)**：图生视频的参考图（首帧）。
   - **Input Video (可选)**：视频扩展时的源视频。
   - **Aspect Ratio (可选)**：比例（默认 16:9）。

### 第2步：执行命令
使用 `scripts/generate_video.py` 执行任务。由于视频生成涉及异步轮询，脚本会等待完成后返回路径。

**命令示例：**
```bash
python scripts/generate_video.py -p "一段特写：两个人在 flickering 的火光下盯着墙上的密码，男人低声说 '这一定是它'。"
```

### 第3步：结果反馈
1. **反馈进度**：告知用户 "视频生成已启动，涉及异步渲染和下载，预计需要 1-5 分钟"。
2. **展示结果**：使用 `Video` 组件展示生成的视频文件路径（`file://` 协议）。

## 命令行参数说明

| 参数 | 说明 |
|------|------|
| `-p` / `--prompt` | 视频描述或对话脚本。 |
| `-i` / `--input-image` | 参考图路径（图生视频）。 |
| `-v` / `--input-video` | 源视频路径（视频扩展）。 |
| `-a` / `--aspect-ratio` | 比例（16:9, 9:16, 21:9 等）。 |
| `-f` / `--filename` | 输出路径，默认存放在 `generated_video/`。 |
